# 🚀 AI Nova — Landing Page

A modern and responsive landing page for **AI Nova**, an artificial intelligence platform designed to help businesses automate workflows, improve productivity, and grow faster.

This project was developed as **Task 1 — Landing Page** for the **Web Development & Designing Internship at Oasis Infobyte**.

---

## 📌 About the Project

AI Nova is a fictional AI technology platform that provides intelligent solutions for business automation.

The goal of this project was to create a visually polished, responsive, and user-friendly static landing page using HTML5 and CSS3.

The website focuses on:

- Modern UI design
- Responsive layouts
- Clear navigation
- Strong call-to-action sections
- Consistent typography and color palette
- User-friendly content structure

---

## ✨ Features

- 📌 Fixed navigation bar
- 🏠 Hero section
- 🤖 AI-focused content
- ⚡ Features section
- ℹ️ About section
- 💬 Testimonials section
- 🚀 Call-to-action section
- 📱 Responsive design
- 🎨 Consistent color palette
- 📝 Clean and readable typography
- 🔗 Footer navigation and social links
